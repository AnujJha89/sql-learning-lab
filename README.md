# SQL Learning Lab

An interactive SQL learning platform with real-time query execution and theory.

---

##  Features
- SQL Query Editor
- Real-time execution
- Theory panel
- Query history
- Table visualization

---

##  Tech Stack
- HTML, CSS, JavaScript
- Node.js, Express
- MySQL

---

##  Installation & Setup

### 1. Clone the repository
git clone https://github.com/AnujJha89/sql-learning-lab.git

### 2. Go to project folder
cd sql-learning-lab

### 3. Install dependencies
npm install

### 4. Create a `.env` file and add:
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=dbms_lab

### 5. Run the server
node server.cjs

### 6. Open in browser
